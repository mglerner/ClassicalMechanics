## Skips

- **Class 12, SHO (5.1-5.2):** looked at vertical-vs-horizontal spring period and amplitude
  independence; a strong upper-division class predicts both correctly, so no vote splits.
  If PHY 210 builds the peg-shadow / circular-motion projection apparatus, borrow it for a
  1-minute look at 5.2's complex exponential, but it is not a prediction demo here.
- **Class 13, light damping changes the period (5.4):** the shift w1 = sqrt(w0^2 - beta^2) is
  too small to see with a lightly damped oscillator, and in water the added-mass shift swamps
  it, so the demo would show the wrong cause. Use `damping-regimes` instead or skip.
- **Class 20, Hamilton's principle (7.1):** no physical demo of "the action is stationary";
  a Python notebook of trial paths with action values does this better than apparatus.
- **Atwood machine via Lagrangian (7.3-7.5):** the apparatus is familiar from intro and its
  result is predicted correctly by everyone; nothing new to vote on. (The swinging Atwood
  machine is a striking chaos demo but takes too long to set up and belongs to Ch 12.)
- **Noether's theorem (7.8):** demos of conserved momentum/angular momentum (air-track
  collisions, rotating stool) only re-show conservation, not the symmetry -> conservation
  link; a whiteboard argument plus the ignorable coordinate in `ball-in-rotating-hoop` (phi is
  driven, so p_phi is NOT conserved there) makes the point better.
- **Lagrange multipliers (7.10):** no demo found that makes the constraint force the
  observable; skip.
- **Classes 01-02, 05-06, 09, 11 (past):** class 05 already had the Helmholtz-coil e-beam;
  rocket (06) and central-force/multiparticle (11) demos found were intro-level with no
  upper-division prediction worth the minutes.
