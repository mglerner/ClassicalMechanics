# Drag (Taylor Ch 2)

Class notebooks for PHY 317, Python versions of Will Raven's Mathematica
demos (his used Manipulate sliders; these use parameter sweeps you edit).
Run on posit.smith.edu.

- `linear_drag.ipynb` -- the f_quad/f_lin three-regime estimate, then the
  closed-form linear-drag solutions (horizontal and vertical, y up) for
  several time constants, Stokes-law taus for real drops, and a numerical
  check. Class 03 (Mon Sep 14).
- `linear_drag_range.ipynb` -- the trajectory y(x) with its vertical
  asymptote at v_x0 tau against the vacuum parabola, the exact range by
  root-finding, and Taylor's small-drag range formula (2.44) versus
  exact. Class 04 (Wed Sep 16).
