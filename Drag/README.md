# Drag (Taylor Ch 2)

Class notebooks for PHY 317, Python versions of Will Raven's Mathematica
demos. Interactive via ipywidgets sliders (`interact`), like his
Manipulate panels. Run on posit.smith.edu (JupyterLab); outputs are
cleared in git, so run the cells.

- `linear_drag.ipynb` -- the f_quad/f_lin three-regime estimate; the
  closed-form linear-drag solutions (y up) with sliders for tau and the
  launch velocity; Stokes-law tau and v_ter for a real drop with sliders
  for diameter, density and medium. Class 03 (Mon Sep 14).
- `linear_drag_range.ipynb` -- the trajectory y(x) with its asymptote
  against the vacuum parabola, sliders for launch velocity and tau, the
  exact range by root-finding vs Taylor's small-drag formula (2.44).
  Class 04 (Wed Sep 16).
